CASE_01 // CAPSTONE ENTERPRISE SYSTEM Laravel 13 • MySQL 8.0 • Tailwind v4

Motaris — POS, Multi-Tier Inventory & Sparepart Recommendation Engine

Sistem informasi operasional front-desk terpadu pada Bengkel Penarukan Motor (Malang) yang mengintegrasikan kasir multi-skema harga (Ritel, Sales, Grosir), manajemen piutang termin, pengadaan Purchase Order (PO), dan algoritma rekomendasi suku cadang alternatif.

Masalah Operasional (Problem)

Transaksi kasir manual memakan 3–5 menit per pelanggan, rawan selisih harga ritel/grosir, serta kehilangan penjualan (lost sales) ketika suku cadang utama kosong.

Solusi Rekayasa (Architecture)

Alur kerja Kasir-First dengan mutasi database atomik, algoritma Rule-Based Specification Matching untuk rekomendasi subtitusi barang, dan 57 pengujian otomatis PHPUnit.

Checkout: < 30 Detik PHPUnit: 57/57 (100% Pass) Skor UAT: 96.6% Laporan: 99% Lebih Cepat

CASE_03 // EDTECH ASSESSMENT ENGINE Python • JavaScript PWA • Offline Engine

Jhâr-Ajhârân — Offline CAT CPNS & BUMN Simulator with Tactical Hints

Platform latihan Computer Assisted Test (CAT) untuk seleksi SKD CPNS, RBB BUMN, serta persiapan TOEIC/IELTS yang berjalan secara offline dengan fitur inovatif Hint Taktik Bertingkat untuk melatih pola pikir analitis peserta.

Masalah Pembelajaran (Problem)

Aplikasi latihan soal konvensional membutuhkan koneksi internet terus-menerus dan langsung memperlihatkan kunci jawaban sehingga pengguna cenderung menghafal, bukan memahami pola.

Solusi Rekayasa (Architecture)

Mesin evaluasi CAT berbasis klien (zero-latency) yang dilengkapi algoritma petunjuk bertingkat (Tiered Hints) serta manajemen paket soal terstruktur berbasis Python.
