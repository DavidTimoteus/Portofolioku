# Portofolioku — David Timoteus Arya Bakti Pamungkas

Website portofolio rekayasa perangkat lunak (**Full-Stack Software Engineer & Systems Architect**) milik **David Timoteus** (`@DavidTimoteus`), dirancang dengan pendekatan **Non-AI-Slop Swiss Editorial × Obsidian Crimson Architecture** (terinspirasi dari design system *Sanity*, *Raycast*, dan *Vercel Geist*).

## Fitur Utama & Standar Industri
- **Palet Warna Obsidian Crimson / Vermilion Red**: Kombinasi warna dasar gelap karbon (`#090809`) dengan aksen merah presisi (`#E11D48` / `#FF3B5C`) serta 3 mode atmosfer (*Obsidian Crimson*, *Velvet Crimson*, dan *Swiss Paper & Red*).
- **Studi Kasus Berstandar Perusahaan (STAR / CAR Method)**: Menyajikan masalah bisnis, arsitektur teknis, dan metrik kuantitatif terverifikasi (`Motaris POS & ERP`, `PWA-MyDuit + Gemini OCR`, `Jhâr-Ajhârân CAT Engine`, `Route Wise × Odoo ERP`).
- **Sinkronisasi Live GitHub API**: Terhubung langsung ke `api.github.com/users/DavidTimoteus/repos` dengan *fallback snapshot* instan.
- **Command Palette (`Ctrl + K`) & Bilingual (`ID` / `EN`)**: Navigasi cepat berbasis keyboard dan dukungan dwibahasa instan.
- **Zero-Dependency & Siap Publikasi**: Dibangun dengan standar web modern murni (HTML5 Semantik, CSS Grid/Custom Properties, ES6+ JavaScript) untuk skor performa maksimal dan stabilitas jangka panjang.

## Menjalankan Secara Lokal
Cukup buka `index.html` di browser atau jalankan server statis:
```bash
npx serve .
# atau
python -m http.server 8080
```
